# GPT-5 Nano - P32 - `fabric_dyeing_three_vat_flowshop_makespan`

## Full problem description

A fabric dyeing plant has 3 dyeing vats. Each batch of fabric must be dyed in sequence in the first, second, and third vats. The plant must color five batches of fabric. The processing time in hours for batch i in vat j is given by the matrix: batch 1: 3, 1, 1; batch 2: 2, 1.5, 1; batch 3: 3, 1.2, 1.3; batch 4: 2, 2, 2; batch 5: 2.1, 2, 3. Schedule the dyeing operations in the vats to minimize the completion time of the last batch.
