# Preserved original generation outputs

The files in this directory were copied byte-for-byte from the supplied `runs.zip`. They are not reconstructed or reformatted.

- `generated_code/` contains extracted generated Python models.
- `responses/` contains raw model responses.
- `prompts/` contains the problem-level generation prompts.
- `full_run/` and `resume_run/` preserve the two source runs separately; the documentation uses the resume copy for overlapping P22/S0.
