# SIRL-Gurobi - P09 - `post_office_scheduling`

## Full problem description

A post office needs a different number of employees each day: Monday 15, Tuesday 13, Wednesday 15, Thursday 18, Friday 14, Saturday 16, Sunday 10. Each employee works five consecutive days and then has two days off. Determine the minimum total number of employees to hire so that each day's requirement is met. An employee who starts on a given day works that day and the next four days.
