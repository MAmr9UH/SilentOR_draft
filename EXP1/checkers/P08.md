# P08 — `fastfood_shift_scheduling` checker documentation

## Full problem description

A 24-hour fast food restaurant divides the day into eight consecutive 3-hour time windows. Four work shifts are available, each covering three consecutive time windows (9 hours). The number of workers required in each window is: 6am-9am needs 55; 9am-12pm needs 46; 12pm-3pm needs 59; 3pm-6pm needs 23; 6pm-9pm needs 60; 9pm-12am needs 38; 12am-3am needs 20; 3am-6am needs 30. Shift 1 covers the windows 6am-9am, 9am-12pm, 12pm-3pm; shift 2 covers 12pm-3pm, 3pm-6pm, 6pm-9pm; shift 3 covers 6pm-9pm, 9pm-12am, 12am-3am; shift 4 covers 12am-3am, 3am-6am, 6am-9am. The wage per worker per 9-hour shift is $135 for shift 1, $140 for shift 2, $190 for shift 3, and $188 for shift 4. Determine the number of workers on each shift to meet all window requirements at minimum total wage cost.
