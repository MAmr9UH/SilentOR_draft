# P44 — three_job_two_machine_flow_shop_makespan

## Problem description

Sequence three jobs through two machines to minimize makespan. Each job occupies exactly one sequence position and every position contains exactly one job. Jobs visit machine 1 and then machine 2. A machine can process only one job at a time, and completion times must respect both within-job machine order and consecutive-position machine order. Use the supplied processing-time matrix; assignment variables are binary and completion times are nonnegative.
