# P42 — aircraft_route_assignment_integer_min_cost

## Problem description

Assign available aircraft types to routes at minimum total cost. The number of aircraft of each type assigned over all routes cannot exceed its availability. Each assigned aircraft contributes its route-specific passenger capability, and the total capability assigned to each route must meet that route's demand. Assignment quantities are nonnegative integers. Use the supplied availability, demand, capability, and cost data.
