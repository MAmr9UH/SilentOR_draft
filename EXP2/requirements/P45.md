# P45 requirements — flight_package_seat_allocation_revenue_max

## Problem description

Choose nonnegative integer quantities of two flight packages to maximize total revenue. Sales of each package cannot exceed its demand. Each sold package reserves one seat on every flight leg indicated by the supplied incidence matrix, and reservations on each leg cannot exceed available seats. Use the supplied seat capacities, demands, revenues, and package-leg incidence data.
