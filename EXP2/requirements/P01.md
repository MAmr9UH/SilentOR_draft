# P01 requirements — red_star_plastic

## Problem description

Red Star Plastic Factory produces 6 types of plastic containers, with their capacities, demands, and variable costs shown in Table 5-11.

Table 5-11
Container Code: 1, 2, 3, 4, 5, 6
Capacity (cm^3): 1500, 2500, 4000, 6000, 9000, 12000
Demand (units): 500, 550, 700, 900, 400, 300
Variable Cost (¥/unit): 5, 8, 10, 12, 16, 18

Each type of container is produced using different dedicated equipment, with a fixed cost of ¥1200. When the quantity of a certain container cannot meet the demand, containers with larger capacities can be used as substitutes. How should production be organized to minimize the total cost while meeting the demand?

## Candidate-facing variable meanings

- `produced` — dict: key '1'..'6' -> gurobipy Var (units produced of each type)
- `allocation` — dict: key 'i,j' (1-indexed, only capacity_i>=capacity_j) -> gurobipy Var

## R1 · demand_satisfaction

For each demand class j in {1,2,3,4,5,6}, the total units allocated to class j, which is the sum of `allocation[i,j]` over all container types i in {1,2,3,4,5,6} whose capacity is at least the capacity of class j, must be >= that class's demand. The demands for classes 1 to 6 are 500, 550, 700, 900, 400, and 300 units respectively.

- Source status: STATED
- Ambiguity flag: false

## R2 · substitution

For every pair (i, j) with `allocation[i,j]` > 0, the capacity of supplying container type i must be >= the capacity of demand class j. Container capacities for types 1 to 6 are 1500, 2500, 4000, 6000, 9000, and 12000 cubic centimetres respectively, so `allocation[i,j]` must be 0 whenever the capacity of type i is less than the capacity of class j.

- Source status: STATED
- Ambiguity flag: false

## R3 · conservation_linking

For each container type i in {1,2,3,4,5,6}, the total units allocated from type i, which is the sum of `allocation[i,j]` over all demand classes j in {1,2,3,4,5,6}, must be <= `produced[i]`. Unused production is permitted, so equality is not required.

- Source status: IMPLIED
- Ambiguity flag: false

## R4 · setup_fixed_cost

For each container type i in {1,2,3,4,5,6}, producing a positive quantity requires the activation indicator to be set: `produced[i]` must be <= a sufficiently large constant multiplied by `open[i]`, so `produced[i]` must be 0 whenever `open[i]` = 0. Each activated `open[i]` incurs a fixed equipment charge of 1200 yuan.

- Source status: STATED
- Ambiguity flag: false

## R5 · integrality

Every `produced[i]` for container types i in {1,2,3,4,5,6} and every `allocation[i,j]` for i,j in {1,2,3,4,5,6} must be integer-valued.

- Source status: IMPLIED
- Ambiguity flag: false

## R6 · non_negativity

Every `produced[i]` for container types i in {1,2,3,4,5,6} and every `allocation[i,j]` for i,j in {1,2,3,4,5,6} must be >= 0.

- Source status: IMPLIED
- Ambiguity flag: false

## R7 · objective

The objective must minimize total cost, computed as the sum over container types i in {1,2,3,4,5,6} of the per-unit cost of type i multiplied by `produced[i]`, plus 1200 multiplied by `open[i]` summed over the same types. The per-unit costs for types 1 to 6 are 5, 8, 10, 12, 16, and 18 yuan respectively.

- Source status: STATED
- Ambiguity flag: false
